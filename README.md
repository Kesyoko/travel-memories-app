## サービス概要
SNSのように他人の評価を気にせず、旅行やお出かけの思い出を記録・共有できる非SNS型旅行記録アプリです。  
写真・場所・感想・支出をまとめて保存し、共有リンクを使用して限られた人とだけ思い出を共有することもできます。  

## このサービスへの思い・作りたい理由
私は幼い頃から家族旅行に行っていましたが、旅行先のホテル名や訪れた場所を記憶するのが苦手ですぐ忘れてしまう子供でした。  
成長後、行動範囲が広がりお出かけや旅行の機会が増えましたが、幼い頃から変わらず「どこでどんな体験をしたか」「いくら使用したか」を忘れてしまい再訪できず後悔することが増えていきました。 
　
改善するため、紙やスマートフォンのメモ機能を試しましたが  
- 紙はなくしてしまう
- 記録した時期がわからなくなる
- 他者に見られてしまう可能性がある  
などの理由から継続できませんでした。

また、SNSは不特定多数に公開され「いいね」などの評価がつく点に苦手意識があり**SNSが苦手な人やSNSに疲れた人も抵抗感なく利用できる記録サービス**があればいいと感じたことが、このアプリを制作するきっかけとなりました。

## ユーザー層について
- SNSでの評価(いいね・閲覧数など)に疲れた人。  
- 親しい人だけでWeb上で記録を残し思い出を分かち合いたい人。  
- 過去に訪れた施設や体験内容、使用金額を忘れてしまい後悔をしたことがある人。  
- 旅先などで撮影した写真を、親しい人と気軽に共有したい人。

## なぜこの層にしたか
- SNSのいいね数などの反応に疲れ、SNSを見るのが辛くなった人も安心して使える記録にしたいと考えたため。  
- 家族などに「旅行の写真見せて」と言われた際、自分のスマートフォンを渡すのに抵抗感があり、かといって物理的なアルバムを作るのも手間だと感じた経験があるため。  
- 「再訪時は〇〇しよう」と話をしても忘れてしまい、旅行終了後思い出した経験があり、もう後悔したくないと考えたため。

## サービスの利用イメージ
１、旅先で写真撮影をする。  
２、記録タイトル、訪れた場所、所在地、写真、メモ、使用金額、日付など入力し保存。  
３、その日の記録を共有する。  
共有リンクを知っている人のみアクセスすることができる仕様で、リンクを受け取った人はアクセスするだけでその日の記録を見ることができ、インターネットやスマートフォン操作が苦手な人でも簡単に見ることができる。   
４、旅行計画時に過去の記録を検索、それをもとに候補地やしたいことの旅行計画作成に活用する。 

※再訪したいと思った時は随時「またいきたい」を選択する。（記録作成時・編集時に選択可能）   


## サービスの差別化ポイント・推しポイント
SNSの代表的な機能（いいね・不特定多数の目に触れる）を排除することで、SNSが苦手な人・SNSに疲れた人でも安心して使用することができると考えました。

具体的な近しいアプリやサービス  
- みてね  
→子ども写真特化型サービスのため、「子ども」ではなく**おでかけ・旅行記録**特化にしています。  
- Googleドライブ  
→文書・写真を共有は可能ですが、多機能ゆえインターネットやスマートフォン操作が苦手な人にとっては操作が難しく感じる場合があります。
 本アプリでは**記録と共有に機能を絞り、直感的に使える設計**を意識しています。    
- インスタ・XなどのSNSサービス  
→他者の投稿が常に表示されること・自身の投稿への反応が可視化される点が特徴ですが、それがSNS疲れや苦手意識に繋がると考えています。  
 本アプリでは**共有リンクを知っている人のみが閲覧できる仕組み**とすることで、他者評価の影響を受けにくい環境を提供しています。  

## 機能
- ユーザー登録・ログイン機能（Devise） 
- Googleログイン機能 
- 旅の記録の作成、詳細確認、削除、更新 
- 写真のアップロード機能（開発環境はActive Storage、本番環境はS3） 
- 詳細確認を対象としたオートコンプリート検索機能 
- Google Places APIを利用したオートコンプリート所在地入力 
- 持ち物リスト 
- 「また行きたい」記録用プルダウン機能 
- 支出記録 
- 共有リンク機能を実装し、ログイン不要での限定共有機能 
- 独自ドメイン 
- プライバシーポリシー 
- お問い合わせフォーム 
- 利用規約 
- 静的OGP 

- RSpecによる品質管理
- GitHub ActionsによるCI構築
